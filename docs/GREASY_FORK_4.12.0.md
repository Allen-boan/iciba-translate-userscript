# Greasy Fork 602070 更新材料（4.12.0）

目标：只更新 https://greasyfork.org/zh-CN/scripts/602070，不创建新脚本。正式名称「极简 AI 划词翻译｜多语言·深入解析」。发布源文件为 `dist/iciba.user.js`，保留现有 namespace、noe132 的 MIT 版权及原项目链接，由 Allen-boan 开发维护 AI 版本。

## 更新说明

新增真正的多语言翻译：一次基础请求自动识别原文并给出简短译文。目标语言默认简体中文，可选择英语、印尼语、日语、韩语、西班牙语、法语、德语、葡萄牙语、俄语、阿拉伯语、泰语、越南语。深入解析按原文实际语言组织，并使用所选目标语言。

发音使用浏览器/系统真实可用的对应语言语音，英语保留美式和英式独立按钮；语音缺失明确提示，不用其他语言冒充。支持停止朗读。划词只显示小圆点，点击才发起翻译，深入解析仍按需调用；可拖动弹窗及内部滚动保持不变。

已有 API Key 与配置保持兼容。基础翻译及解析缓存分别隔离目标语言；遇到不能解析的响应会安全报错，不显示语言元数据。不恢复传统 Provider，不新增历史、生词本、全文翻译或聊天侧栏。

## 建议公开使用说明

1. 安装或更新同一脚本 602070，在 AI 设置中选择 DeepSeek、OpenAI 或自定义 HTTPS 兼容接口。
2. 输入自己的 API Key，主动获取模型，选择或手动输入模型 ID，并选择目标语言后保存。
3. 在网页中选词、短语或句子，点击小圆点查看简短译文；按需点击深入解析。
4. 需要时点击原文发音。英语有独立英美口音；其他语言只有对应语音实际可用才可朗读。缺少声音时不会自动改用其他语言。

只有主动请求的选中文本会发送到用户指定的 API 服务商。密钥保存在本机脚本管理器，不上传到 Greasy Fork。AI 使用费用由所选服务商收取；浏览器朗读不调用 AI 语音 API，不消耗 AI Token，部分浏览器声音可能由浏览器自己的在线语音服务提供。
