# 多语言版本实现与发布计划

目标：单次基础请求获取译文与源语言，目标语言驱动基础翻译及按需解析，匹配真实浏览器语音；保留已有交互、脚本身份和 GM 密钥。

1. 扩展可选 targetLanguage 配置，缺失时按简体中文读取，保留原存储键/schema/修订绑定。目标语言设置不影响模型获取和密钥隔离。
2. 建立语言目录、结构化基础响应解析；格式缺失时保留 unknown，格式损坏时安全报错，不直接展示元数据，不自动补请求。纯译文降级仅保留译文且不推测英语。
3. 基础与解析缓存分别加入目标语言、提示词版本；基本缓存连同源语言保存。解析依实际语言组织内容，响应语言与目标一致，仍仅点击后请求。
4. 发音适配器匹配真实语言，英语口音严格区分，其他语言优先标准地区再选择同语言可用语音；处理延迟加载/缺失/停止，未知语言不猜英语。
5. 更新设置页、弹窗语言按钮与主动停止，保留圆点/拖动/滚动/取消。正式名称用于界面和 @name:zh-CN，本地安装识别所用默认 @name、namespace、GM 存储键及 Greasy Fork 602070 保持不变，更新已有脚本而不另建重复脚本。
6. 扩展多语言、解析、配置迁移、缓存、发音及交互回归测试；完整 Jest、ESLint、TypeScript、生产构建及产物语法/凭据扫描，版本 4.12.0。
7. 检查可用浏览器中的实装及语音，真实 AI 请求仅使用用户现有已授权接口且按最小范围；若无法实际执行则明确待验收。更新已有 Greasy Fork 602070，核对名称、版本、源码、安装链接，不新建重复脚本，不额外 Commit 或 Push。
