## 配置入口

当前设置窗口直接显示 AI 表单，流程为「选择服务商或填写自定义地址 → 输入 API Key → 点击验证密钥并获取模型 → 搜索并选择模型 → 保存」。

- 默认 DeepSeek，官方 Base URL 自动填写；OpenAI 也使用官方地址，模型不再由本地固定列表决定。
- 自定义兼容接口的 HTTPS Base URL 始终可见，用户可使用任意符合原有 URL 安全校验的接口；不通过密钥前缀或其他服务商探测密钥归属。
- 只有明确点击获取按钮才向当前地址追加 /models，发送一次带 Bearer 密钥的 GET；没有生成、逐模型测试、自动重试或其他服务商探测。查询支持超时和取消。
- 候选列表去重、排序、支持搜索；按名称和返回元数据排除明显的嵌入、重排、音频/实时、图像/视频等专用模型。筛选是启发式，不保证所有候选都支持 Chat Completions 或翻译；未知能力模型明确标示。可能被筛掉或未列出的模型允许手动指定。
- /models 不支持、失败、格式不符或没有候选时显示说明并展开手动模型 ID 输入。自定义模式不会继承 DeepSeek 默认模型；未填写或选择模型不能保存。已有有效配置的模型继续显示，无需重新获取才能使用。
- 查询失败或取消不保存配置；只有点击保存才持久化选定 Base URL 和模型。模型列表不写入 GM，也不写第二套密钥。原有配置和密钥记录的键及 schema 不变。
- 密钥继续保存在闭包及 GM 存储中，不进入公共响应式状态；保存、关闭和切换接口清空输入框。切换服务商、地址或密钥会取消旧查询、丢弃列表并忽略迟到响应；旧密钥不会自动用于新地址。
- 模型列表可读取不等同于密钥具备所有模型权限。高级设置中的「测试选中模型」仍是一次主动的简短生成请求，可能产生费用，不自动保存或测试其他模型。开发验证只使用模拟响应。
- 为支持用户明确指定的自定义域名，元数据保留官方 @connect 并增加 @connect *；实际请求仍只使用验证后的当前 Base URL，禁用重定向并检查最终地址。name、namespace、存储键与 MIT 声明不变。

## 请求与兼容范围

`src/service/ai/index.ts` 提供统一接口：

- `createChatCompletion` 返回 `{ promise, cancel }`；不自动重试、不更换模型或翻译来源。
- `testAiConnection` 发送固定的短文本，独立于阅读内容。
- `buildBasicTranslationMessages` 和 `buildDetailedAnalysisMessages` 是独立、无网络副作用的提示词构建函数，分别用于基础翻译和用户主动请求的深入解析。

客户端使用脚本管理器的 `GM.xmlHttpRequest` 或 `GM_xmlhttpRequest`，发送带 Bearer 认证的匿名 JSON POST。接口前缀保留 `/v1` 或代理子路径，并拼接 `/chat/completions`。

OpenAI 官方域使用 `max_completion_tokens`；DeepSeek 官方域使用 `max_tokens` 并关闭 thinking；自定义兼容域使用 `max_tokens`，不添加厂商扩展。首版不保证所有推理模型、代理参数方言和非 Chat Completions 协议均可使用。

请求支持超时、取消及静态脱敏错误。不会把服务器响应原文、认证头或密钥放进错误消息；不使用浏览器 fetch 作为失败兜底。重定向会被拒绝，运行时仍需脚本管理器正确支持 `redirect: 'error'`；响应 URL 检查不能代替阻止重定向。

元数据预声明 OpenAI 和 DeepSeek 官方域。自定义域可能需要脚本管理器单独授权，不使用全域 `@connect *`。

现有元数据中的两个 AI 域名声明属于此前保留的修改，尚未在浏览器中回归旧 Provider 的域名授权行为。旧 Provider 源码保留，不代表各管理器中的旧翻译请求已经验证通过。

## 密钥和存储边界

AI 配置和密钥使用独立、版本化的 GM 键，不读取或覆盖原有 Provider、历史记录等存储。普通响应式状态只保存配置和是否已有密钥，不保存密钥内容。

GM 存储不等于加密保险箱，密码输入框也不提供与宿主网页的绝对隔离。建议在可信页面中配置，不将真实密钥写入源码、日志、测试或网页 localStorage。用户自行配置的服务会接收到测试文本及后续主动请求内容。

以下要求已在第二阶段业务代码中接入，完整构建和浏览器真实体验尚待验证。其他已确定的第二阶段要求保持不变。

- 划词翻译弹窗提供「美式发音」「英式发音」两个按钮，朗读当前选中的英语原文，支持单词、短语和完整句子。
- 优先使用浏览器原生 Web Speech API（SpeechSynthesis）。只在用户点击对应按钮时朗读，划词、打开弹窗、翻译完成和语音列表更新均不得自动播放。
- 根据浏览器实际提供的语音语言标记分别检测 `en-US` 与 `en-GB`，为对应口音设置实际匹配的 voice；不能仅修改 utterance 的 lang，也不能用默认语音、通用 `en` 或另一种口音冒充缺失口音。

- 处理语音列表首次为空及后续异步更新的情况。列表更新只刷新可用状态，不自动朗读；播放前重新确认对应语音仍可用。

## 第三阶段：按需深入解析

基础翻译成功后，原弹窗显示「深入解析」按钮。选区出现、基础翻译完成、语音列表更新或缓存中已有解析均不会自动请求或展开解析。用户点击后，才用现有 GM 配置发送一条独立的 Chat Completions 请求；仅发送同一段选中文字，不附带网页其他内容、历史记录或此前译文。

- `src/service/ai/analysis.ts` 管理独立的解析状态、取消、缓存与收展。读取凭据和请求在途时同步防重；成功后收起、展开直接使用当前结果，不重新读取密钥或发送请求。错误不缓存，不自动重试，用户可以显式重试或取消。
- 解析加载、失败或取消不清除基础译文，也不停止或启动朗读。切换选区、关闭弹窗、打开设置或卸载时，旧解析请求会失效并尽力取消；迟到响应既不更新显示，也不写入缓存。
- 基础翻译与解析使用独立缓存。解析缓存仅在当前页面内存中保留，有效期 5 分钟、最多 50 项 LRU；按 Base URL、模型、实际密钥、独立的 `AI_DETAIL_PROMPT_VERSION` 和原文隔离。重新选中相同文本后，仍需点击按钮才检查解析缓存；当前已显示的成功结果收展不受缓存有效期影响。
- 解析请求的输出上限为 1536 tokens，超时 45 秒；通过原有客户端处理认证、限流、拒答、截断、超时和网络错误，不自动重发。
- 模型依据材料本身判断单词、短语或句子，类型提示仅供参考。提示词要求简洁中文、按学习价值取舍，涵盖词义区别、搭配与适用词形、例句、固定表达与场景、句子主干、从句修饰及地道语气，不机械套用所有栏目。基础翻译提示词及其版本保持不变。
- 模型结果和错误继续使用 Vue 普通文本插值展示；不使用 `v-html`，不执行模型输出的 HTML。

第三阶段新增解析控制器测试，并扩展提示词与弹窗联动测试。18 项独立跨模块内存模拟检查通过，覆盖无预取、请求防重、收展复用、基础与解析缓存分离、密钥变化、错误与超时、取消及迟到响应、只发送选中文字、纯文本输出和发音独立性。29 个 TypeScript 文件语法检查、13 个纯模块严格类型检查、6 个测试文件类型检查均无错误；新增解析区域的 Vue 模板内存编译无错误。

第三阶段功能开发期间没有安装依赖、修改锁文件、调用真实付费 API 或重新生成 `dist/iciba.user.js`。当时完整 Jest、ESLint、生产构建、新产物语法及真实浏览器体验均待验证；依赖恢复后的正式验证结果见下节。
