# 多语言 4.12.0 验证记录

2026-10-25，基线 `feat/ai-translation` / `1cb9df8`，实际旧版本为 4.11.19，本次版本为 4.12.0。

## 已实现

- 自动源语言识别与简洁译文在同一次基础请求中返回，结构为 sourceLanguage / translation。支持 JSON 和 JSON 围栏；缺失或无效语言标记保持未知，不把元数据展示为译文、不默认英语、不自动补请求；明确无元数据的纯译文保留兼容降级。
- 13 项目标语言设置，默认简体中文；基础翻译与按需解析均使用目标语言。独立缓存键包含目标语言及提示词版本，基础缓存同时保留源语言。解析上下文目标与当前配置不一致时提示重新翻译，避免基础译文与解析语言混用。
- 深入解析按原文实际语言组织词形、语法、搭配、语气及语域，明确禁止把英语模板机械套用于其他语言；仍不预取解析、不附带其他网页内容。
- SpeechSynthesis 英美口音严格分开，其他语言只匹配相同语言的可用语音，优先对应地区及本地语音；同语言地区回退时使用实际 voice.lang，不冒充英语口音。支持延迟 voiceschanged、缺失提示、主动停止、选区/关闭停止。未知源语言不提供猜测发音。
- 旧 GM schema、配置/密钥键和接口绑定保持兼容；读取旧配置不写入存储，缺少 targetLanguage 时按简体中文使用，保存新目标仍可复用原有同接口密钥。默认 @name 和 @namespace 均保留，正式中文名称由 @name:zh-CN、界面及 README 展示。
- 旧 Provider 清理状态维持，不恢复任何旧服务，不新增历史、生词本、全文翻译或侧栏。依赖与锁文件未变，损坏依赖目录未清理、移动或覆盖。原 MIT 版权、noe132 署名与原项目链接保留，Allen-boan 标记为 AI 版本开发维护者。
